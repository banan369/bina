# بينا — الخير يتبادل

منصة مجتمعية عربية RTL لتبادل المساعدة والمهارات بدون مقابل مادي، متوافقة مع النشر على GitHub Pages تحت المسار `/bina/`.

## الوظائف
- تسجيل وإنشاء الحساب عبر Supabase Auth مع تأكيد البريد.
- ملف شخصي مرتبط بمعرّف المستخدم وقابل للتعديل.
- طلبات وعروض حقيقية في جدول `posts` ومرتبطة بصاحبها.
- لوحة مستخدم تعرض الإحصاءات والنشاط والتقييمات الفعلية فقط.
- محادثات خاصة وأسماء حقيقية للطرف الآخر.
- سياسات RLS تمنع تعديل أو حذف بيانات مستخدم آخر.
- حالات تحميل وفراغ وأخطاء عربية.

## التشغيل المحلي

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## إعداد Supabase (مطلوب)
1. افتح **SQL Editor** في مشروع Supabase المرتبط بالموقع.
2. نفّذ كامل ملف [`supabase.sql`](supabase.sql). الملف migration قابل لإعادة التشغيل، وينشئ الجداول والفهارس والـ triggers والسياسات ودوال المحادثات الآمنة.
3. تأكد أن `supabase-config.js` يحتوي فقط على Project URL ومفتاح anon/publishable العام. لا تستخدم `service_role` في المتصفح.
4. أضف `https://banan369.github.io/bina/` إلى **Authentication → URL Configuration → Redirect URLs**.

> لا تعمل ميزات الحسابات والكتابة قبل تطبيق migration. لا توجد بيانات تجريبية أو آلية LocalStorage بديلة؛ الواجهة تعرض فقط بيانات Supabase الحقيقية.

## الملفات الرئيسية
- `index.html`: الصفحة وأقسام لوحة التحكم وواجهة الرسائل.
- `styles.css`: الهوية الحالية والتجاوب وحالات الواجهة.
- `app.js`: Auth والملف والمنشورات واللوحة والرسائل والتقييمات.
- `supabase.sql`: مخطط قاعدة البيانات وRLS ودوال RPC الآمنة.
- `supabase-config.js`: إعداد الاتصال العام بـ Supabase.
